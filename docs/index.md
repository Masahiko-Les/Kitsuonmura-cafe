# 吃音村カフェ サポート

吃音村カフェは、吃音のある人が、カフェで語り合うように自分の経験や気持ちを言葉にし、ほかの村人が残した言葉にふれるiPhoneアプリです。自分の「できたこと」を種にして蒔き、水やりをして花を咲かせることもできます。

## よくある質問

### カフェではどんなことをするの？
カフェに入り、マスターのふくろうに話しかけるか、テーブルに座ると会話が始まります。テーマを選ぶと、マスターが3つの質問を順に聞きます。答えたあとに、同じ質問へのほかの村人の言葉を読めます。質問はスキップでき、時間の制限もありません。

### 書いた言葉は、ほかの人に見えるの？
3つの質問すべてに答えて「届けてもよい」を選び、運営が確認した言葉だけが、ほかの村人に届きます。名前は出ません。「自分だけにしておく」を選ぶと、ほかの村人には届きません。

### 届けた言葉を取り消したい
カフェの「わたしの言葉」から、会話ごとに非公開にしたり、削除したりできます。

### 「共感しました」などを押すとどうなるの？
その言葉を書いた本人だけに、気持ちが届きます。数は公開されません。

### いやな言葉を見つけたら？
言葉の下にある「この言葉を通報する」を押してください。通報した言葉は、すぐにあなたの画面から消え、運営が確認します。

### 「できたこと」はどうやって蒔くの？
村の草地や畑のマスに立ち、Aボタンを押します。3行・80字まで書けます。道には蒔けません。「できたこと」はこのiPhoneの中だけに保存され、ほかの村人には見えません。

### 花はいつ咲くの？
1つの種に、1日1回水やりできます。3回水やりをすると花が咲きます。

### 機種変更するときは？
「できたこと」は、「設定」の「バックアップを保存」でファイルに保存し、新しいiPhoneの「バックアップから戻す」で読み込めます。アプリを削除すると消えるので、先に保存してください。

### データを消したい
アプリの「設定」→「すべてのデータを削除」から、カフェの言葉、届いた気持ち、村人名、匿名アカウント、このiPhoneの「できたこと」を消せます。消したデータは元に戻せません。

アプリを先に削除すると、サーバーのデータをアプリから消せなくなります。アプリを削除する前に、この操作を行ってください。
