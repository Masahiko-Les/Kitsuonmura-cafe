# プライバシーポリシー

吃音村カフェ 運営（以下「運営」）は、iPhoneアプリ「吃音村カフェ」（以下「このアプリ」）で扱う情報について、次のとおり定めます。

## 1. 集める情報

このアプリは、メールアドレスや電話番号での登録を必要としません。サーバーに保存するのは、次の情報だけです。

| 情報 | 内容 |
| --- | --- |
| 匿名ID | はじめて起動したときに自動で作られる、ランダムな識別番号です。 |
| 村人名 | あなたが決めた、アプリの中での呼び名です。 |
| カフェの言葉 | カフェの質問に答えて書いた文章と、そのテーマ、質問、日時、公開の状態です。同じ会話の回答は、ひとまとまりとして記録します。 |
| 届けた気持ち | 読んだ言葉に届けた気持ちの種類と、どの言葉に届けたかの記録です。 |
| 通報 | 通報した言葉と、通報した日時です。 |
| 規約への同意 | 同意した日時と、利用規約の版です。 |

カフェの言葉は、書いた時点でサーバーに保存されます。会話のおわりに「自分だけにしておく」を選んだ言葉も、サーバーに保存されたままです。

次の情報はサーバーに送らず、あなたの端末の中だけに保存します。

- 「できたこと」の種と花、水やりの記録
- 通報して表示しないようにした言葉の一覧
- カフェで話した回数と、評価のお願いを出したかどうかの記録

「できたこと」のバックアップは、あなたが共有シートで選んだ保存先に、ファイルとして保存されます。

このアプリでは、次のものを**集めません**。

- 本名、住所、メールアドレス、電話番号
- 位置情報、連絡先、写真
- 広告のための識別子

広告は表示しません。アプリやウェブサイトをまたいで、あなたの行動を追うこと（トラッキング）もしません。

カフェの言葉には、吃音や体調、気持ちなど、あなたの心身に関わることを書く場合があります。本名や連絡先など、あなたやほかの人がわかる情報は書かないでください。

## 2. 使いみち

集めた情報は、次のことだけに使います。

- カフェで言葉を残す、ほかの村人の言葉を読む、気持ちを届ける、といったアプリの機能を提供するため
- 「届けてもよい」を選んだ言葉を、ほかの村人に届ける前に確認するため
- 通報された言葉を確認し、規約に反するものを非公開にしたり削除したりするため
- 命に関わるようなつらい気持ちが書かれた言葉を確認するため

## 3. ほかの村人に見えるもの

- **カフェの言葉**：3つの質問すべてに答え、「届けてもよい」を選び、運営が確認した言葉だけが、ほかの村人に届きます。同じ会話の3つの言葉は、ひとまとまりで届きます。
- **村人名**：ほかの村人の画面には表示しません。カフェの言葉は「村人」とだけ紹介します。
- **届けた気持ち**：言葉を書いた本人だけが見られます。数は公開しません。
- **「できたこと」**：ほかの村人にも、運営にも見えません。

## 4. 運営が見るもの

運営は、アプリの運営画面で次の言葉を読みます。

- 「届けてもよい」を選んだ言葉
- 通報された言葉
- 命に関わるようなつらい気持ちが書かれた言葉

命に関わるようなつらい気持ちが書かれた言葉は、ほかの村人には届けません。書いた本人には、相談窓口をお知らせします。匿名のため、運営から本人に連絡することはできません。

また、運営はサーバーの管理者として、保存されたカフェの言葉を見られる立場にあります。不具合の調査など、運営に必要な場合を除き、「自分だけにしておく」を選んだ言葉を読むことはありません。

## 5. 情報の保管と委託

サーバーの情報は、Google LLC が提供する Firebase（Cloud Firestore と Firebase Authentication）に保存します。

- 保存先のサーバーは、日本の外（アメリカ合衆国など）にある場合があります。
- Google は、運営の委託を受けて情報を保管します。
- Google での情報の扱いについては、[Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy)をご覧ください。

運営は、法令にもとづく場合を除き、あなたの同意なく情報を第三者に提供しません。

## 6. 保存する期間と削除

情報は、あなたが削除するまで保存します。

カフェの言葉は、「わたしの言葉」から会話ごとに非公開にしたり、削除したりできます。1つの会話の言葉は3つで1まとまりなので、非公開にすると3つともほかの村人に届かなくなります。

アプリの「設定」→「すべてのデータを削除」から、いつでも次のものを削除できます。

- あなたのカフェの言葉
- あなたが届けた気持ちと、あなたに届いた気持ち
- 村人名などの登録情報と、匿名ID
- 端末の「できたこと」と、通報して表示しないようにした言葉の一覧、カフェで話した回数

ご注意いただきたいこと：

- **アプリを削除する前に**、「すべてのデータを削除」を行ってください。匿名IDは端末に保存されているので、先にアプリを削除すると、サーバーの情報をアプリから消せなくなります。その場合は、下のお問い合わせ先にご連絡ください。
- 次のものは、安全のための記録として残ります。
  - あなたが送った通報と、あなたの言葉に届いた通報の記録
- 次のものは、端末やあなたの保存先に残ります。
  - 評価のお願いを出したかどうかの記録
  - あなたが保存した「できたこと」のバックアップファイル
- 「できたこと」はサーバーにないので、アプリを削除すると元に戻せません。残したいときは、先にバックアップを保存してください。
- 運営は、規約に反する書き込みを、あなたの操作を待たずに非公開にしたり削除したりすることがあります。

## 7. お子さまの利用について

このアプリは、年齢によって使える機能を分けていません。未成年の方は、保護者の方と一緒にこのポリシーと利用規約を読んでから使ってください。
